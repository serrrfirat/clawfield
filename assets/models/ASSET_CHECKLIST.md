## Style Guide (paste into every prompt)
**Core keywords:** `Low poly flat-shaded, minimal polygons, simple geometric blocky shapes, solid flat colors, game asset, no background`

## Post-Generation Steps (3D AI Studio)
1. Generate with prompt below
2. Apply **Hunyuan Smart Topology** → **High** reduction → **Triangle** mesh
3. Export as **GLB**
4. Drop into the matching folder path
